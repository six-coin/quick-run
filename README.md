# Fast Run

Windows 上的键盘启动器：按一次 `Alt+Space` 唤出搜索框，输入几个字母就能打开文件、文件夹、网页，或者执行命令。附带的**操作管理器**用网页界面维护这份操作清单。

---

## 1. 安装

需要 Windows 10 及以上（管理器依赖系统自带的 WebView2 运行时），以及 [uv](https://docs.astral.sh/uv/)。

```bat
git clone <仓库地址> "Fast Run"
cd "Fast Run"
setup.bat
```

`setup.bat` 会创建 `.venv` 虚拟环境并安装依赖。也可以手动执行：

```bat
uv sync
```

升级依赖或换机器时重跑一次 `setup.bat` 即可，依赖版本由 `uv.lock` 锁定。

## 2. 启动

| 文件 | 作用 |
|---|---|
| `main.bat` | 启动常驻后台的启动器，之后用 `Alt+Space` 唤出 |
| `manager.bat` | 打开操作管理器窗口 |
| `setup.bat` | 安装 / 更新虚拟环境 |

两个 `.bat` 都用 `.venv` 里的 `pythonw.exe` 运行，不会留下控制台窗口。

想让启动器开机自启，把 `main.bat` 的快捷方式放进
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`。

> 启动器是常驻进程，双击 `main.bat` 后界面上不会出现任何东西，这是正常的——按 `Alt+Space` 才会弹出。

## 3. 启动器

### 3.1 基本用法

输入几个字母，列表按**前缀匹配**给出操作，回车执行。

| 按键 | 作用 |
|---|---|
| `Alt+Space` | 唤出 / 收起启动器 |
| `↑` `↓` | 上下选择 |
| `Enter` | 执行选中项 |
| `Esc` | 收起 |
| `Shift+↑` `Shift+↓` | 翻输入历史 |
| `Ctrl` / `Shift` / `Alt` + `Enter` | 打开文件时改为打开它所在的文件夹；对翻译行则改为朗读原文 |

输入框只接受单行文本，右键菜单已关闭。

### 3.2 用序号直接选中

在关键词后面加 `#n`，直接取第 n 个匹配项，回车即执行：

```
leidian#1      → 第一个匹配 leidian 的操作
play#2         → 第二个匹配 play 的操作
```

序号从 1 开始。超出范围会提示「未知序号」；只输入 `#` 或不带数字的 `#` 会被当作普通文字。

### 3.3 浏览文件夹

给「打开文件夹」类型勾选**允许浏览子文件夹**之后，输入 `关键词` + 空格即可进入浏览模式。下表中的 `␣` 表示一个空格：

| 输入 | 结果 |
|---|---|
| `play␣` | 列出该文件夹的内容 |
| `play␣a` | 列出名字里含 a 的条目 |
| `play␣a␣` | 进入第一个匹配项，列出它的内容 |
| `play␣a␣␣` | 进入第二个匹配项 |
| `play␣a#2` | 只显示第二个匹配项 |

规则可以概括成：

- 关键词后面第一个空格进入浏览模式，此时列出根目录；
- 之后每个 token 选一层；
- token 后面**空格的个数**决定选第几个匹配项（1 个空格 = 第 1 个），`#n` 可以显式指定；
- 最后一个 token 后面没有空格时，只列出匹配项，不进入。

匹配同时支持拼音，`biji` 能找到「笔记」。进入的层数受「探索深度」限制：单条操作的深度与 `app.json` 里的全局上限取较小值，最大 5 层。

### 3.4 内置功能

没有命中任何操作时，列表会自动给出这几项：

| 行 | 回车做什么 |
|---|---|
| **搜索** | 用默认浏览器打开必应搜索结果 |
| **计算** | 结果复制到剪贴板（支持 `+ - * / // % **` 和括号） |
| **翻译** | 打开百度翻译页面；按住 `Ctrl`/`Shift`/`Alt` 则朗读原文 |
| **查词** | 用大模型给出释义（需要配置 API Key） |

在查询末尾加一个反引号 `` ` `` 可以跳过操作匹配，只保留上面这些内置行。

翻译和查词都需要在管理器里配置密钥，见 [5.4 设置](#54-设置)。

## 4. 操作管理器

`manager.bat` 打开。左边是分组树，右边是编辑区，改动即时写入内存，按 `Ctrl+S` 或点「保存文件」才落盘。

### 4.1 分组

- 操作按分组组织，**分组的顺序就是启动器里结果的顺序**；
- 拖拽分组标题可以调整顺序；
- 分组标题右侧的开关控制整组启用/关闭，关闭的组不参与搜索，配置保留；
- 拖拽操作可以调整组内顺序，拖到别的分组标题上即移动到该组末尾；
- 分组标题上的 `+` 在该组新建操作；列表末尾的虚线 `+` 新建分组。

### 4.2 操作类型

| 类型 | 必填参数 | 说明 |
|---|---|---|
| 打开文件 | `path` | 用系统默认程序打开。`no_window` 控制是否隐藏命令行窗口 |
| 打开文件夹 | `dir` | 用资源管理器打开。可开启子文件夹浏览并设置探索深度 |
| 打开网页 | `url` | 用默认浏览器打开 |
| 执行命令 | `command` | 在工作目录 `程序目录` 下执行，保留控制台窗口 |
| 程序调试 | `function` | 重启或关闭 Fast Run 自身 |

文件路径支持用 `|` 分隔多个，回车时一起打开。

### 4.3 匹配字串

决定输入什么能命中这条操作，只允许**小写字母 `a-z`** 和分隔符 `|`：

- 保存时自动转小写、丢弃其他字符、合并连续的 `|`、去掉首尾 `|` 并去重；
- 全部清理完为空会被判为「匹配字串不能为空」，无法保存；
- 多个关键词之间是「或」的关系，命中任意一个即可。

例如 `leidian|ld` 表示输入 `leidian` 或 `ld` 都能命中。

### 4.4 设置

点标题栏右侧的齿轮：

| 项目 | 说明 |
|---|---|
| 语言 | 中文 / English，切换后整个界面立即生效 |
| 外观 | 浅色 / 深色。首次启动跟随系统，之后以这里的选择为准 |
| 最大扫描深度 | 文件夹浏览的全局层数上限，0–5 |
| 单目录条目上限 | 一个目录超过这个数量就不展开，避免卡顿 |
| 百度翻译 | `appid` 与密钥都填了才启用翻译 |
| AI 查词 | 填入 API Key 后启用查词 |

密钥输入框默认隐藏内容，点右侧的眼睛图标可以临时显示。

### 4.5 键盘操作

左侧列表整体只占**一个** `Tab` 停靠点：

| 按键 | 作用 |
|---|---|
| `Tab` | 进入列表一次，再按就离开 |
| `↑` `↓` | 在分组与操作之间移动 |
| `Home` `End` | 跳到首 / 尾 |
| `Enter` `空格` | 选中当前项；选中的是折叠的分组时同时展开 |
| `←` | 折叠分组，或从操作跳回所属分组 |
| `→` | 展开分组 |
| `Ctrl+S` | 保存 |
| `Ctrl+F` | 定位到搜索框 |

弹窗打开时 `Tab` 只在弹窗内循环，`Esc` 关闭。分组行上的加号和开关只支持鼠标，需要键盘操作时选中分组，在右侧面板里改。

## 5. 配置与数据

```
config/app.json          应用设置
config/operations.json   操作与分组
logs/                    运行日志
custom/                  你自己的脚本等素材（相对路径以程序目录为基准）
```

`config/`、`logs/`、`custom/` 都是本机数据，已在 `.gitignore` 中排除。删除 `config/` 后下次启动会重新生成一份示例配置。

### 5.1 app.json

```json
{
  "language": "zh",
  "theme": "light",
  "navigation": { "max_depth": 5, "max_entries": 100 },
  "translate": { "appid": "", "secret_key": "" },
  "ai": { "api_key": "" }
}
```

`theme` 只在文件不存在时读一次系统偏好，之后以文件里的值为准。

### 5.2 operations.json

根层就是分组数组：

```json
[
  {
    "name": "常用",
    "enabled": true,
    "operations": [
      {
        "display": "打开记事本",
        "type": "file",
        "keywords": "notepad|np",
        "arguments": { "path": "C:\\Windows\\notepad.exe", "no_window": false }
      }
    ]
  }
]
```

字段含义见 [4.2](#42-操作类型) 和 [4.3](#43-匹配字串)。手改文件后需要重启启动器才会生效；管理器每次打开都会重新读取。

### 5.3 日志

每次启动生成一个日志文件，`logs/main_*.log` 或 `logs/manage_*.log`，单个文件超过 5 MB 轮转，保留 14 天。程序异常退出时会弹窗给出日志路径。

## 6. 常见问题

**按 `Alt+Space` 没有反应**
热键被别的程序占用了。日志里会写「注册失败（错误码 1409）」，同时启动时会弹窗提示。关掉占用该热键的程序（常见的是另一个启动器、录屏工具）后重新运行 `main.bat`。

**管理器窗口一片空白**
检查系统是否安装了 WebView2 运行时。Windows 11 自带；Windows 10 可能需要安装 [Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

**翻译不生效**
`appid` 和 `secret_key` 必须都填。只填一个会被当作未配置。

**按住 Ctrl 回车没有朗读**
朗读依赖 python-vlc 和本机的 VLC 播放器。没有安装时程序照常运行，只是没有声音。

**改了 `app.json` 的外观，启动器没变**
启动器只在启动时读一次配置，重启 `main.bat` 生效。管理器里的切换是即时的。

**想回退到默认配置**
关闭程序，删掉 `config/` 目录，重新启动即可生成示例配置。
