一、分组

  • 操作按分组组织。分组之间的顺序，就是启动器里结果的排列顺序。
  • 点击分组标题可以编辑分组名称，或用右侧开关整组关闭；关闭的分组不参与搜索。
  • 分组标题右侧的“+”直接在该组里新建一条操作；列表最下方的“+”用来新建分组。
  • 拖拽分组标题可以调整分组顺序。

二、操作类型

  • 打开文件：用系统默认程序打开一个文件。可勾选“无窗口运行”以避免弹出命令行窗口。
  • 打开文件夹：用文件资源管理器打开一个文件夹。可勾选“允许浏览子文件夹”以启用输入空格浏览子目录的功能（需设置探索深度）。
  • 打开网页：用默认浏览器打开一个网址。
  • 执行命令：在命令行中执行一条命令。
  • 程序调试：重启或关闭 Fast Run 程序。

三、字段说明

  • 显示名称：在结果列表中显示的文本。
  • 运行方式：选择操作的类型。
  • 匹配字串：只允许小写字母 a-z 和分隔符 |，前缀匹配。保存时会自动清理非法字符与多余的 |。
  • 切换到组：把当前操作移动到别的分组（操作详情底部的按钮）。

四、文件夹浏览

  • 勾选“允许浏览子文件夹”后，在主搜索框输入关键词加空格即可进入该文件夹的子文件浏览模式。
  • 探索深度控制最多可以进入多少层子文件夹。0 表示仅显示根目录内容，2 表示可以进入一层子文件夹。
  • “设置”里还能限制全局的最大扫描深度和单目录条目上限；超过条目上限的文件夹不会被展开。
  • 浏览模式下支持拼音搜索和序号选择（例：关键词 a#2）。

五、键盘操作

  • 左侧列表是一个整体：整张列表只占一个 Tab 停靠点，Tab 进来一次，再按就离开了。
  • 列表里可选中的只有三种：展开的分组、折叠的分组、展开分组里的操作。
  • ↑ ↓ 在它们之间移动，Home / End 到首尾。
  • Enter 或 空格 选中当前项；如果选中的是折叠的分组，会同时把它展开。
  • ← 折叠分组，或从操作跳回它所属的分组；→ 展开分组。
  • 底部「展开全部 / 折叠全部」可以一次改完所有分组的折叠状态。
  • 加号和启用开关不参与键盘选择，选中分组后在右侧面板里操作。
  • 弹窗打开时，Tab 只在弹窗内部循环，Esc 关闭弹窗。
  • 全局快捷键：Ctrl + S 保存，Ctrl + F 搜索。

六、设置

  • 语言、外观、扫描上限与外部服务密钥都保存在 config/app.json，界面上改完即时生效。
  • 外观在第一次启动时跟随系统，之后一直使用你最后选择的模式。
