1. Groups

  • Operations are organised in groups. The order of the groups is the order results appear in the launcher.
  • Click a group title to edit its name, or use the switch on the right to disable the whole group; disabled groups are skipped when searching.
  • The “+” next to a group title adds an operation to that group; the “+” at the bottom of the list creates a new group.
  • Drag a group title to change the group order.

2. Action types

  • Open file: opens a file with its default program. Tick “Run without window” to hide the console window.
  • Open folder: opens a folder in File Explorer. Tick “Allow browsing subfolders” to enable the “keyword + space” browsing mode (a depth is required).
  • Open URL: opens an address in the default browser.
  • Run command: runs a command in a console window.
  • Debug: restarts or closes Fast Run itself.

3. Fields

  • Display name: the text shown in the result list.
  • Action type: what the operation does.
  • Match keywords: only lowercase a-z and the separator | are kept; matching is by prefix. Illegal characters and redundant | are removed on save.
  • Move to group: moves the current operation to another group (button at the bottom of the editor).

4. Folder browsing

  • With “Allow browsing subfolders” enabled, type the keyword plus a space in the launcher to browse that folder.
  • Explore depth limits how many subfolder levels this operation may enter. 0 lists the root only; 2 allows one level of subfolders.
  • Settings also provide a global maximum scan depth and a per-folder item limit; folders above the limit are not expanded.
  • Browsing supports pinyin search and index selection (for example keyword a#2).

5. Keyboard

  • The sidebar is a single tab stop: press Tab once, then use ↑ ↓ to move between groups and operations.
  • Enter or Space selects the focused item; ← collapses a group or jumps back to it, → expands it.
  • The “+” and the switch on a group row are their own tab stops; press Enter or Space to activate them.
  • While a dialog is open, Tab cycles inside it and Esc closes it.
  • Global shortcuts: Ctrl + S saves, Ctrl + F focuses the search box.

6. Settings

  • Language, appearance, scan limits and service keys live in config/app.json and take effect immediately.
  • Appearance follows the system on first launch; afterwards your last choice is kept.
