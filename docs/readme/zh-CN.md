# 快捷运行 使用手册

Windows 上的键盘启动器：按一次 Alt+Space 唤出搜索框，输入几个字母就能打开文件、文件夹、网页，或者执行命令。附带的快捷运行操作管理器用网页界面维护这份操作清单。

[English](en-US.md)

---

## 1. 安装

需要 Windows 10 及以上（管理器依赖系统自带的 WebView2 运行时），以及 [uv](https://docs.astral.sh/uv/)。

```bat
git clone <仓库地址> "Quick Run"
cd "Quick Run"
setup.bat
```

`setup.bat` 会创建 `.venv` 虚拟环境并安装依赖。也可以手动执行：

```bat
uv sync
```

升级依赖或换机器时重跑一次 `setup.bat` 即可，依赖版本由 `uv.lock` 锁定。

包索引固定在项目根的 `uv.toml`，用的是官方 PyPI，所以 `uv.lock` 里记录的是官方地址，任何机器 clone 下来都能直接装，不依赖本机的全局 uv 配置。

国内网络慢的话，把 `uv.toml` 里的 `url` 换成镜像（例如 `https://mirrors.aliyun.com/pypi/simple/`）再执行 `uv lock`。注意锁文件会跟着变成镜像地址，这类改动不要提交。

## 2. 启动

| 文件            | 作用                            |
|---------------|-------------------------------|
| `main.bat`    | 启动常驻后台的启动器，之后用 `Alt+Space` 唤出 |
| `manager.bat` | 打开快捷运行操作管理器窗口                 |
| `setup.bat`   | 安装 / 更新虚拟环境                   |

两个启动脚本都用 `.venv` 里的 `pythonw.exe` 运行，不会留下控制台窗口。

想让启动器开机自启，把 `main.bat` 的快捷方式放进
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`。

> 启动器是常驻进程，双击 `main.bat` 后界面上不会出现任何东西，这是正常的——按 `Alt+Space` 才会弹出。

**第一次运行**时，无论先双击哪个入口，都会打开管理器：先选界面语言（默认跟随 Windows 的系统语言，没有对应语言包就用英语；下拉框一改，界面立刻切成那种语言），再读一遍使用说明。如果先点的是 `main.bat`，读完说明后还会多一句提示，说明刚打开的其实是管理程序。设置完成后重新双击原来的入口即可。

两个入口都是单实例的：重复双击 `main.bat` 会提示「已经在运行」；重复打开管理器会把它提到前面。

## 3. 启动器

### 3.1 基本用法

输入几个字母，列表按**前缀匹配**给出操作，回车执行。

| 按键                                 | 作用                           |
|------------------------------------|------------------------------|
| `Alt+Space`                        | 唤出 / 收起启动器                   |
| `↑` `↓`                            | 上下选择                         |
| `Enter`                            | 执行选中项                        |
| `Esc`                              | 收起                           |
| `Shift+↑` `Shift+↓`                | 翻输入历史                        |
| `Ctrl` / `Shift` / `Alt` + `Enter` | 打开文件时改为打开它所在的文件夹；对翻译行则改为朗读原文 |

输入框只接受单行文本，右键菜单已关闭。列表里单击选中一行，双击直接执行。

### 3.2 用序号直接选中

在关键词后面加 `#n`，直接取第 n 个匹配项，回车即执行：

```
leidian#1      → 第一个匹配 leidian 的操作
play#2         → 第二个匹配 play 的操作
```

序号从 1 开始。超出范围会提示「未知序号」；只输入 `#` 或不带数字的 `#` 会被当作普通文字。

### 3.3 浏览文件夹

给「打开文件夹」类型勾选**允许浏览子文件夹**之后，输入 `关键词` + 空格即可进入浏览模式。下表中的 `␣` 表示一个空格：

| 输入         | 结果              |
|------------|-----------------|
| `play␣`    | 列出该文件夹的内容       |
| `play␣a`   | 列出名字里含 a 的条目    |
| `play␣a␣`  | 进入第一个匹配项，列出它的内容 |
| `play␣a␣␣` | 进入第二个匹配项        |
| `play␣a#2` | 只显示第二个匹配项       |

规则可以概括成：

- 关键词后面第一个空格进入浏览模式，此时列出根目录；
- 之后每个 token 选一层；
- token 后面**空格的个数**决定选第几个匹配项（1 个空格 = 第 1 个），`#n` 可以显式指定；
- 最后一个 token 后面没有空格时，只列出匹配项，不进入。

匹配同时支持拼音，`biji` 能找到「笔记」。进入的层数受「探索深度」限制：单条操作的深度与 `app.json` 里的全局上限取较小值，最大 5 层。

### 3.4 内置功能

没有命中任何操作时，列表会自动给出这几项：

| 行      | 回车做什么                                  |
|--------|----------------------------------------|
| **搜索** | 用默认浏览器打开必应搜索结果                         |
| **计算** | 结果复制到剪贴板（支持 `+ - * / // % **` 和括号）     |
| **翻译** | 打开百度翻译页面；按住 `Ctrl`/`Shift`/`Alt` 则朗读原文 |
| **查词** | 用大模型给出释义（需要配置 API Key）                 |

在查询末尾加一个反引号 `` ` `` 可以跳过操作匹配，只保留上面这些内置行。

翻译和查词都需要在管理器里配置密钥，见 [4.4 设置](#44-设置)。

## 4. 快捷运行操作管理器

`manager.bat` 打开。左边是分组树，右边是编辑区，改动即时写入内存，按 `Ctrl+S` 或点「保存文件」才落盘。窗口打开时光标已经在搜索框里，直接敲字就能筛。

### 4.1 分组

- 操作按分组组织，**分组的顺序就是启动器里结果的顺序**；
- 拖拽分组标题可以调整顺序；
- 分组标题右侧的开关控制整组启用/关闭，关闭的组不参与搜索，配置保留；
- 拖拽操作可以调整组内顺序，拖到别的分组标题上即移动到该组末尾；
- 分组标题上的 `+` 在该组新建操作；页脚「新建分组」在列表末尾新建一个分组。

### 4.2 操作类型

| 类型    | 必填参数       | 说明                                |
|-------|------------|-----------------------------------|
| 打开文件  | `path`     | 用系统默认程序打开。`no_window` 控制是否隐藏命令行窗口 |
| 打开文件夹 | `dir`      | 用资源管理器打开。可开启子文件夹浏览并设置探索深度         |
| 打开网页  | `url`      | 用默认浏览器打开                          |
| 执行命令  | `command`  | 在程序目录下执行，保留控制台窗口                  |
| 程序调试  | `function` | 重启或关闭 Quick Run 自身                |

文件和文件夹操作各有一个**路径基准**下拉框，决定填进去的路径怎么补全：

| 选项          | 相对路径的起点                                                        |
|-------------|----------------------------------------------------------------|
| 数据目录下的相对路径  | 数据目录（默认在 `%PROGRAMDATA%\six-coin\quick-run`，可改），`custom\` 就在这里 |
| 程序文件夹下的相对路径 | 程序所在的文件夹，也就是放 `main.bat` 的地方                                   |
| 绝对路径        | 不做补全，按填写的路径原样使用                                                |

三种基准都只在路径**不是**绝对路径时才起作用：写了 `D:\Tools\x.exe` 这种完整路径，选哪种基准都指向同一个文件。文件路径支持用 `|` 分隔多个，回车时一起打开。

切换基准时，下面路径输入框里的示例文字会跟着变，照着例子的样子填就行：

| 基准    | 文件路径示例                 | 文件夹路径示例    |
|-------|------------------------|------------|
| 绝对路径  | `E:\data\example.json` | `E:\data\` |
| 数据目录  | `custom\example.bat`   | `custom\`  |
| 程序文件夹 | `manager.bat`          | `docs\`    |

文件夹路径保存时会自动补上结尾的 `\`（`E:\data` 存成 `E:\data\`）。

启动器执行任何操作时，工作目录恒为程序目录，不会跟着目标文件或文件夹跑。

### 4.3 匹配字串

决定输入什么能命中这条操作，只允许**小写字母 `a-z`** 和分隔符 `|`：

- 保存时自动转小写、丢弃其他字符、合并连续的 `|`、去掉首尾 `|` 并去重；
- 全部清理完为空会被判为「匹配字串不能为空」，无法保存；
- 多个关键词之间是「或」的关系，命中任意一个即可。

例如 `leidian|ld` 表示输入 `leidian` 或 `ld` 都能命中。

### 4.4 设置

点标题栏右侧的齿轮：

| 项目       | 说明                                               |
|----------|--------------------------------------------------|
| 语言       | 内置简体中文 (中国) / English (US)，切换后整个界面立即生效；列表按语言代码排序 |
| 外观       | 只有浅色 / 深色两种，首次启动按系统偏好定一次，之后不再跟随系统                |
| 淡入时长     | 启动器弹出时的动画毫秒数，0–1000，填 0 表示不做动画。改完要重启启动器          |
| 淡出时长     | 启动器收起时的动画毫秒数，同上                                  |
| 最大扫描深度   | 文件夹浏览的全局层数上限，0–5                                 |
| 单目录条目上限  | 一个目录超过这个数量就不展开，避免卡顿                              |
| 百度翻译     | `appid` 与密钥都填了才启用翻译                              |
| AI 查词    | 填入 API Key 后启用查词                                 |
| AI 查词提示词 | 发给模型的系统提示词，决定回答风格；留空或点「恢复默认提示词」回到内置那一份           |

面板下面是三块内容，之间没有分隔线：

- **数据目录**：一行是输入框和「更改」「重置」两个按钮，下一行是这行设置的说明。改目录会自动补上 `quick-run` 这一层，重启后生效并把旧内容搬过去。
- **使用说明**：右边的「打开」按钮显示当前语言的手册。
- **版本**：当前程序的版本号。

密钥输入框默认隐藏内容，点右侧的眼睛图标可以临时显示。面板底部左边是「重置所有设置」（语言与外观一起恢复默认，操作列表不受影响），右边是「完成」。

如果填过百度翻译或 AI 查词的凭据，确认框会多一句警告和一个「保留隐私信息」按钮：选它只把其余设置恢复默认，APP ID、密钥和 API Key 都留着。

设置面板只能通过「完成」、右上角的 × 或 `Esc` 关闭；点面板外面不会关掉它。其他弹窗（使用说明、确认框）按 `Esc` 或点外面的空白处都能关。

### 4.5 键盘操作

左侧列表整体只占**一个** `Tab` 停靠点：

| 按键           | 作用                   |
|--------------|----------------------|
| `Tab`        | 进入列表一次，再按就离开         |
| `↑` `↓`      | 在分组与操作之间移动           |
| `Home` `End` | 跳到首 / 尾              |
| `Enter` `空格` | 选中当前项；选中的是折叠的分组时同时展开 |
| `←`          | 折叠分组，或从操作跳回所属分组      |
| `→`          | 展开分组                 |
| `Ctrl+S`     | 保存                   |
| `Ctrl+F`     | 定位到搜索框               |

弹窗打开时 `Tab` 只在弹窗内循环，`Esc` 关闭最上面那一层。分组行上的加号和开关只支持鼠标，需要键盘操作时选中分组，在右侧面板里改。

## 5. 配置与数据

程序目录只放代码和 `setup.bat`；运行期文件全在系统目录里。

```
%PROGRAMDATA%\six-coin\quick-run\       数据目录（可更改）
├─ app.json                             应用设置
├─ operations.json                      操作与分组
└─ custom\                              你自己的脚本等素材（路径基准选「数据目录」即可引用）

%LOCALAPPDATA%\six-coin\quick-run\
├─ logs\                                运行日志
├─ locks\                               锁
└─ data-dir.txt                         数据目录指针

%TEMP%\six-coin\quick-run\              临时目录，可随时删
```

数据目录的最后一层恒是项目代号：选 `D://Data` 得到 `D://Data//quick-run`。换目录时旧内容在下次启动搬过去，目标已有的同名文件不覆盖。删除 `<数据目录>\app.json` 后下次启动会重新问一次语言并生成默认配置。

### 5.1 app.json

```json
{
    "language": "zh-CN",
    "theme": "light",
    "navigation": {
        "max_depth": 5,
        "max_entries": 100
    },
    "translate": {
        "appid": "",
        "secret_key": ""
    },
    "ai": {
        "api_key": "",
        "prompt": "你是一个词典助手，功能如下：…"
    }
}
```

`ai.prompt` 是 AI 查词的默认系统提示词，默认值与界面语言无关；写成空串时按内置那份处理。

`language` 取 `app/locales` 里存在的语言代码，不认识就回退 `en-US`。`theme` 只有 `light` / `dark`；只在文件不存在时读一次系统偏好，之后以文件里的值为准。

### 5.2 operations.json

根层就是分组数组：

```json
[
    {
        "name": "默认分组",
        "enabled": true,
        "operations": [
            {
                "display": "操作管理与帮助",
                "type": "file",
                "keywords": "manager",
                "arguments": {
                    "path": "manager.bat",
                    "base": "program",
                    "no_window": true
                }
            }
        ]
    }
]
```

`base` 就是「路径基准」，取值 `data`（数据目录）、`program`（程序文件夹）、`absolute`（绝对路径）。这个键**必须写**：缺了、写成空串，或写了别的值，启动器会直接报配置错误并指出是哪一条操作。

字段含义见 [4.2](#42-操作类型) 和 [4.3](#43-匹配字串)。手改文件后需要重启启动器才会生效；管理器每次打开都会重新读取。

### 5.3 日志

每次启动生成一个日志文件，`%LOCALAPPDATA%\six-coin\quick-run\logs\main_*.log` 或 `manage_*.log`，单个文件超过 5 MB 轮转，保留 14 天。程序异常退出时会弹窗给出时间、错误与日志路径。

## 6. 多语言

内置两种：`zh-CN`（简体中文）与 `en-US`（English）。语言文件放在 `app/locales`，**文件名就是语言代码**：

```
app/locales/zh-CN.json
app/locales/en-US.json
```

程序启动时扫描这个目录，目录里有什么语言就支持什么语言，不需要改代码。

### 添加一种语言

1. 复制 `app/locales/en-US.json`，重命名为目标语言代码，例如 `ja-JP.json`；
2. 逐条翻译值，**键名保持不变**，`{name}` 这类占位符也原样保留；
3. 把 `language.name` 改成该语言自己的写法（例如 `"日本語"`），设置里的语言列表显示的就是这个值；
4. 重启管理器，语言列表会自动多出这一项。

`language.name` 没填时，界面会退回显示语言代码本身（`ja-JP`）。

其他约定：

- 缺键会回退到 `zh-CN`，不会出现裸露的键名，所以可以先把文件放进去再慢慢补翻译；
- 删掉某个 JSON 就等于移除该语言，配置文件里的旧值会自动回落到 `zh-CN`。

## 7. 常见问题

**按 `Alt+Space` 没有反应**

热键被别的程序占用了。日志里会写「注册失败（错误码 1409）」，同时启动时会弹窗提示。关掉占用该热键的程序（常见的是另一个启动器、录屏工具）后重新运行 `main.bat`。

**管理器窗口一片空白**

检查系统是否安装了 WebView2 运行时。Windows 11 自带；Windows 10 可能需要安装 [Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

**翻译不生效**

`appid` 和 `secret_key` 必须都填。只填一个会被当作未配置。

**按住 Ctrl 回车没有朗读**

朗读依赖 python-vlc 和本机的 VLC 播放器。没有安装时程序照常运行，只是没有声音。

**改了 `app.json` 的外观，启动器没变**

启动器只在启动时读一次配置，重启 `main.bat` 生效。管理器里的切换是即时的。

**想回退到默认配置**

关闭程序，删掉 `%PROGRAMDATA%\six-coin\quick-run\app.json` 与 `operations.json`，重新启动即可生成示例配置。
