# 配置与数据格式

程序只认两个配置文件，都在**数据目录**下（默认 `%PROGRAMDATA%\six-coin\quick-run`）。两者都是 UTF-8 的 JSON，写入使用「临时文件 + `os.replace`」的原子替换，中途崩溃不会留下写了一半的文件。

首次启动时若文件不存在，会自动生成一份可用的示例内容。

| 位置                                               | 内容             |
|--------------------------------------------------|----------------|
| `<数据目录>\app.json`                                | 应用设置           |
| `<数据目录>\operations.json`                         | 操作与分组          |
| `<数据目录>\custom\`                                 | 用户脚本与素材        |
| `%LOCALAPPDATA%\six-coin\quick-run\data-dir.txt` | 数据目录指针，改目录后写这里 |
| `%LOCALAPPDATA%\six-coin\quick-run\logs\`        | 日志             |

数据目录在设置页「数据目录」一节里改：一行是输入框与「更改」「重置」，下一行是说明。落点自动补上 `quick-run`，写进 `data-dir.pending`，**下次启动**把旧目录的内容搬过去再改指针；目标已有的同名文件不覆盖。

## 1. `app.json`

应用级设置。

```json
{
    "language": "zh-CN",
    "theme": "light",
    "animation": {
        "in_ms": 200,
        "out_ms": 100
    },
    "navigation": {
        "max_depth": 5,
        "max_entries": 100
    },
    "translate": {
        "appid": "",
        "secret_key": ""
    },
    "ai": {
        "api_key": "",
        "prompt": "你是一个词典助手，功能如下：…"
    }
}
```

| 字段                       | 类型  | 默认    | 取值与行为                                                               |
|--------------------------|-----|-------|---------------------------------------------------------------------|
| `language`               | 字符串 | 系统语言  | `app/locales` 下已有的语言代码；没有匹配或无法识别时回退 `en-US`                         |
| `theme`                  | 字符串 | 系统偏好  | `light` / `dark`，没有 `system`；首次启动读一次系统偏好，旧值 `system` 在读取时定成当时的浅色/深色 |
| `animation.in_ms`        | 整数  | `200` | 0–1000，越界夹取；0 表示不做动画；非数字回退 200                                      |
| `animation.out_ms`       | 整数  | `100` | 同上，管收起时的淡出                                                          |
| `navigation.max_depth`   | 整数  | `5`   | 0–5，越界夹取；非数字回退 5                                                    |
| `navigation.max_entries` | 整数  | `100` | 1–10000，越界夹取；非数字回退 100                                              |
| `translate.appid`        | 字符串 | `""`  | 与 `secret_key` 同时非空才启用翻译                                            |
| `translate.secret_key`   | 字符串 | `""`  | 同上                                                                  |
| `ai.api_key`             | 字符串 | `""`  | 非空才启用查词                                                             |
| `ai.prompt`              | 字符串 | 内置提示词 | 发给模型的系统提示词；留空或删掉时回到 `app/prompts.py` 里的默认值                        |

说明：

- `theme` 只在**文件不存在**时读取一次系统偏好写入；之后无论系统怎么变都以文件为准。
- `animation.in_ms` 管弹出时的淡入，`animation.out_ms` 管收起时的淡出（`Esc`、失去焦点、回车执行后都算）。两者都只在启动器启动时读一次，改完要重启 `main.bat`。
- `max_depth` 是全局上限。单条文件夹操作自己还有一个「探索深度」，实际生效的是两者中较小的那个。
- `max_entries` 控制单个目录的条目上限，超过就不展开，避免大目录卡住界面。
- `ai.prompt` 就是设置页「AI 查词提示词」里的那一大段文字。默认值只有一份，与界面语言无关；清空后保存会写回默认值，不会留下空的 system 消息。
- 字符串字段在读取时会 `strip()`，避免手改文件时留下的空格导致「看起来填了其实没填」。

`AppConfig` 在内存里是扁平结构（`max_depth` 而不是 `navigation.max_depth`），写盘时再还原成嵌套形式，调用方不必层层取属性。

## 2. `operations.json`

操作清单。**根层就是分组数组**，顺序即启动器结果的顺序。

```json
[
    {
        "name": "常用",
        "enabled": true,
        "operations": [
            {
                "display": "打开记事本",
                "type": "file",
                "keywords": "notepad|np",
                "arguments": {
                    "path": "C:\\Windows\\notepad.exe",
                    "no_window": false
                }
            },
            {
                "display": "打开学习资料",
                "type": "dir",
                "keywords": "study",
                "arguments": {
                    "dir": "E:\\Study",
                    "allow_explore": true,
                    "explore_depth": 2
                }
            }
        ]
    }
]
```

### 2.1 分组

| 字段           | 类型  | 必填 | 说明                           |
|--------------|-----|----|------------------------------|
| `name`       | 字符串 | 否  | 为空时读取为「未命名分组」；保存时同样兜底        |
| `enabled`    | 布尔  | 否  | 默认 `true`。`false` 时整组跳过，配置保留 |
| `operations` | 数组  | 否  | 默认空数组                        |

数组本身不能为空，至少需要一个分组。

### 2.2 操作

| 字段          | 类型  | 必填 | 说明                                       |
|-------------|-----|----|------------------------------------------|
| `display`   | 字符串 | 是  | 结果列表里显示的名字，不能为空                          |
| `type`      | 字符串 | 是  | `file` / `dir` / `url` / `cmd` / `debug` |
| `keywords`  | 字符串 | 是  | 匹配字串，见 2.3                               |
| `arguments` | 对象  | 是  | 按类型不同，见 2.4                              |

读取时缺失的 `arguments` 键会用该类型的默认值补齐，未知的键原样保留——这样以后加参数不会让旧配置报错，也不会在保存时丢掉用户手写的扩展字段。

### 2.3 匹配字串

只允许小写字母 `a-z` 和分隔符 `|`。保存时依次执行：

1. 转小写；
2. 丢弃其他所有字符；
3. 按 `|` 切分，丢掉空段（`"a||b|"` → `"a|b"`）；
4. 去重（`"a|a|b"` → `"a|b"`）；
5. 重新用 `|` 连接。

清理后为空即视为「没填」，保存会被拦下并提示「匹配字串不能为空」。

匹配时是前缀匹配：关键词 `lei` 能命中 `leidian`，但 `idian` 不能。多个关键词之间是「或」。

### 2.4 各类型的参数

| 类型      | 参数              | 默认          | 说明                        |
|---------|-----------------|-------------|---------------------------|
| `file`  | `path`          | `""`        | 必填。可用 `\|` 分隔多个路径，回车时一起打开 |
|         | `base`          | 必填          | 路径基准，见 2.5；缺了或写错会报配置错误    |
|         | `no_window`     | `false`     | 隐藏命令行窗口                   |
| `dir`   | `dir`           | `""`        | 必填。同样支持 `\|` 分隔           |
|         | `base`          | 必填          | 路径基准，见 2.5；缺了或写错会报配置错误    |
|         | `allow_explore` | `true`      | 是否允许「关键词 + 空格」进入浏览        |
|         | `explore_depth` | `0`         | 0–5，实际生效值还要与全局上限取小        |
| `url`   | `url`           | `""`        | 必填。反斜杠会被转成正斜杠             |
| `cmd`   | `command`       | `""`        | 必填。工作目录固定为程序目录            |
| `debug` | `function`      | `"restart"` | `restart` 或 `close`       |

路径字段在保存时会去掉首尾引号并把 `/` 转成 `\`；文件夹路径还会在每段末尾补上 `\`（`E:\data` → `E:\data\`），保存后一眼能看出是目录。

### 2.5 路径基准

`file` 与 `dir` 各有一个 `base` 参数，决定**相对路径**从哪里补全：

| 取值         | 含义          | 相对路径的起点                          |
|------------|-------------|----------------------------------|
| `data`     | 数据目录下的相对路径  | `<数据目录>`（`custom\foo.py` 指的就是那儿） |
| `program`  | 程序文件夹下的相对路径 | `app.paths.PROGRAM_DIR`          |
| `absolute` | 绝对路径        | 不做补全；万一填的仍是相对路径，按程序目录处理          |

- 绝对路径不受 `base` 影响，原样使用。
- `base` 是必填项，**没有默认值**：条目里不写、写成空串、或写了三个值以外的内容，读取时都会抛 `ConfigError`，程序直接报错退出，而不是猜一个基准。
- 解析发生在**执行时**，`app/paths.py::resolve_user_path()` 是唯一入口；解析结果与进程 cwd 无关。
- 启动器打开文件 / 文件夹、以及「关键词 + 空格」浏览的根目录，都走同一套补全规则。
- 子进程的工作目录恒为程序目录，不跟着目标文件跑。
- 启动时 `bootstrap.prepare()` 会建好 `<数据目录>` 与 `<数据目录>\custom`，选 `data` 基准时落点已经存在。

## 3. 校验时机

| 时机    | 检查内容                                                                       |
|-------|----------------------------------------------------------------------------|
| 读取    | 顶层必须是数组；分组必须是对象；`operations` 必须是数组；每条操作必须有四个键；`file` / `dir` 必须有合法的 `base` |
| 保存前   | 先归一化（清理匹配字串、整理路径、补文件夹结尾的 `\`），再逐条检查必填字段与路径基准                               |
| 启动器启动 | 只读取，不校验；损坏的配置直接报错并弹窗                                                       |

保存时只报**第一条**错误，并把选中项跳到出错的操作用于修正。这样用户不会一次面对十几个红框。

## 4. 语言包

`app/locales/{语言代码}.json` 是扁平的键值表，文件名就是语言代码：

```json
{
    "language.name": "简体中文 (中国)",
    "manager.title": "快捷运行操作管理器",
    "manager.count": "{total} 项 · {groups} 组"
}
```

- 键名用点分小写英文，值是该语言的最终文本。
- `language.name` 是这门语言**用自己文字书写的名字**，设置里的语言列表直接显示它；缺失时退回语言代码。程序里没有任何硬编码的语言名。
- `{name}` 形式的占位符由 `i18n.t("键", name=值)` 填充；占位符对不上时原样返回模板，不会抛异常。
- 其他语言缺键时回退 `zh-CN`，界面上不会出现裸露的键名。
- 类型、字段、调试动作的显示名由 `type.<类型>`、`field.<字段>`、`debug.<动作>` 三类键提供，代码里按值拼接查询。

语言目录在启动时扫描，新增语言只要放一个同结构的 JSON 文件；具体步骤见 [extending.md](extending.md)。

## 5. 日志

`%LOCALAPPDATA%\six-coin\quick-run\logs\main_*.log` 与 `manage_*.log`，每次启动新建一个。单个文件超过 5 MB 轮转，保留 14 天。

格式：

```
[级别] [YYYY-MM-DD HH:MM:SS] 消息
```

日志路径永远是绝对路径，由 `app.paths.LOG_DIR` 决定。
