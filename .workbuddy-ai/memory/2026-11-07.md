## Fast Run 第十一轮（全折叠后 Tab 失效的真正根因）

- 根因：`listNodes()` 直接 `querySelectorAll('[data-node]')`，折叠分组里的操作虽然 `display:none` 但仍被算进来；roving tabindex 的 0 号停靠点一旦落在这些隐藏节点上，整张列表就没有可聚焦元素了——所以“全折叠时什么都 Tab 不到”。
- 修复：`listNodes()` 用 `offsetParent !== null` 过滤可见节点；`finishListRender` 里 `activeId` 指向隐藏节点时不再采用，选中项是操作但已被折叠时退到它所属的分组标题。
- 侧栏进一步化简：加号、启用开关彻底退出键盘序列（`tabIndex = -1`，仅鼠标可用），可选中的只有「展开的分组 / 折叠的分组 / 展开组里的操作」。删掉 `rowControls` 与行内左右导航。

- 底部新增「展开全部 / 折叠全部」两个并排按钮（`expandAll` / `collapseAll`，只改 `state.collapsed` 后重渲染）。
